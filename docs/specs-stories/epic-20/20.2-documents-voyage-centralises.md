# Story 20.2 — Documents de voyage centralisés

**Titre** : Ajouter un onglet "Docs importants" centralisant vols, hébergement, assurance et réservations

**Priorité** : P2

---

## Objectif fonctionnel

Centraliser dans un écran dédié les informations aujourd'hui dispersées dans les champs `anecdotes`/`history` des lieux tagués "Vol" (numéro de vol, horaires, bagages, référence de réservation), et donner un emplacement aux documents qui n'ont aujourd'hui aucun endroit dédié (hébergement, assurance/santé).

## Règles métier exactes

- Nouvel écran listant les documents par catégorie : Vols, Hébergement, Assurance/Santé, Réservations diverses.
- La catégorie Vols réutilise les données déjà présentes dans `content/places.ts` (pas de ressaisie).
- Les catégories sans équivalent actuel (Hébergement, Assurance/Santé) s'appuient sur un nouveau contenu déclaratif (ex. `content/documents.ts`), au même titre que le reste du contenu voyage.
- Consultable hors-ligne : l'app dispose déjà d'un mode hors-ligne MVP (story 6.1) — aucune dépendance réseau pour ces informations.
- Accessible à tous les profils sans condition de déblocage, au même titre que la checklist (story 10.3).

## Cas limites

- Catégorie sans aucun document renseigné → état vide explicite, la catégorie reste visible plutôt que masquée.
- Informations sensibles (n° de réservation) → même niveau de confidentialité que le contenu déjà présent dans `places.ts`, pas de chiffrement additionnel à ce stade.

## Critères d'acceptation testables

1. Un onglet "Docs importants" est accessible depuis le Dashboard ou le menu principal.
2. Les informations de vol déjà présentes dans `places.ts` apparaissent dans la catégorie Vols sans ressaisie.
3. Les catégories Hébergement et Assurance/Santé existent (même vides au lancement), prêtes à être complétées par du contenu.
4. L'écran reste consultable hors-ligne (mode avion).
5. L'écran est accessible à tous les profils sans déblocage préalable.

## Hors périmètre

- Upload de photos/scans de documents par l'utilisateur (v2 éventuelle) — contenu texte structuré uniquement pour cette story.
- Partage/export des documents vers un tiers.

## Priorité

P2

## Validation attendue

Tests unitaires (regroupement par catégorie), test manuel en mode avion.

## Contraintes UX

Réutiliser les composants de carte/fiche déjà utilisés pour les lieux (cohérence visuelle avec le Guide).
