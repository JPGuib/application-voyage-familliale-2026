# Story 22.2 — Graphique de progression des scores dans le temps

**Titre** : Ajouter une visualisation de l'évolution du score jour après jour dans l'écran Résultats

**Priorité** : P3

---

## Objectif fonctionnel

En complément du podium cumulé (story 19.2), qui ne montre qu'un état final, ajouter une visualisation de l'évolution du score de chaque profil jour après jour, basée sur l'historique déjà stocké (`GameHistoryEntry`).

## Règles métier exactes

- Graphique basé sur l'historique existant (`day`, `quizScore`, `correctCount`, `riddleSolved`, `challengeDone`, `totalScore`).
- Par défaut, affiche l'évolution du score total cumulé du profil courant jour après jour.
- Un sélecteur permet de basculer l'affichage sur un autre profil de la famille (cohérent avec le fait que les scores sont déjà visibles de tous via le podium).
- Le propriétaire, s'il joue, peut être inclus dans ce graphique individuel (contrairement au podium qui l'exclut, story 19.2) — cette vue est une consultation personnelle, pas un classement.

## Cas limites

- Profil n'ayant joué aucun jour → graphique vide avec message explicite plutôt qu'un graphique cassé/à zéro trompeur.
- Un seul jour joué → affichage d'un point unique, pas de courbe, sans erreur.
- Jour sans défi complété par le profil → le point de ce jour reflète le score réellement obtenu (0 ou score partiel), cohérent avec la règle "pas de pénalité, juste absence de gain" déjà définie en story 19.2.

## Critères d'acceptation testables

1. L'écran Résultats propose une vue graphique de l'évolution du score cumulé jour après jour.
2. Le profil affiché par défaut est le profil courant ; un sélecteur permet de choisir un autre profil de la famille.
3. Le propriétaire peut être affiché dans cette vue individuelle même s'il est exclu du podium.
4. Un profil sans historique affiche un état vide explicite, pas d'erreur ni de graphique trompeur.

## Hors périmètre

- Comparaison simultanée de plusieurs profils sur le même graphique (un profil à la fois dans cette story).
- Répartition par thème (Quiz vs Énigme vs Défi) dans le graphique — cumul du score total uniquement ; le détail par thème existe déjà ailleurs dans l'écran Résultats.

## Priorité

P3

## Validation attendue

Tests unitaires (construction des points du graphique depuis `GameHistoryEntry`), test manuel avec un historique multi-jours réel.

## Contraintes UX

Cohérent avec le ton ludique déjà présent (badges, trophées) ; privilégier un graphique simple et lisible sur mobile (courbe ou barres), pas un dashboard analytique complexe.
